# E-Commerce Business Intelligence & Customer Analytics Using SQL

## Project Overview
This project focuses on analyzing Brazilian e-commerce transactional data using MySQL to uncover business insights and evaluate sales performance, customer purchasing behavior, product trends, and delivery operations.

## Technologies Used
- MySQL 8.0+
- SQL
- MySQL Workbench

## Key Features
- Relational database design with seven interconnected tables.
- Data cleaning and data quality validation.
- Sales and revenue trend analysis.
- Customer purchasing and repeat-order analysis.
- RFM-based customer segmentation.
- Product category and seller performance analysis.
- Payment method and delivery performance analysis.
- Advanced SQL analytics using CTEs and Window Functions.
- Reusable SQL views and query execution-plan analysis.

## Dataset
Brazilian E-Commerce Public Dataset by Olist.

Source: https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

## Business Outcomes
The analysis supports business decisions related to customer retention, sales growth, product performance, and delivery improvement.
